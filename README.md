# Stringless

A lightweight client-side Fabric mod that gives players fine-grained control over the rendering of placed string (tripwire) blocks.

Designed for builders and content creators who use string to suppress vine, bamboo, and other block growth — without the visual clutter during exploration or screenshots.

## Features
- Client-side only — no server installation required
- Does not affect gameplay or block behavior
- Multiple rendering modes:
  - **Always Visible** — vanilla behavior
  - **Always Hidden** — string is never rendered
  - **Holding String** — string visible only when holding string in main or off hand
  - **Looking At** — string visible only when looking directly at it
- Compatible with Sodium
- Multiplayer-safe
